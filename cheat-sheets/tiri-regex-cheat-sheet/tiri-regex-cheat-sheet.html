Tiri Regular Expressions Cheat Sheet Pattern syntax & core API

Create patterns

digits = r'\d+'                                        -- preferred simple format
words  = regex.new([[\p{L}+]], regex.ICASE)            -- format for additional options
name   = 'report[1].txt'
exact  = regex.new('^' .. regex.escape(name) .. '$')   -- make user strings safe
exact.test('report[1].txt')                            -- true

r'\d+' is equivalent to regex.new([[\d+]]). In an ordinary quoted string, double regex backslashes: regex.new('\\d+').

Invalid patterns raise ERR_Syntax. Wrap dynamic or user-supplied patterns in try.

Choose an interface

InterfaceResult / purpose
regex.new(pattern, [flags])Compile a dynamic pattern
regex.escape(text)Quote arbitrary text for a pattern
rx.test(text, [flags])Boolean: any match exists
rx.findFirst(text, [offset], [flags])First start, exclusive stop, captures
rx.findAll(text, [offset], [flags])Iterator of positions and captures
rx.extract(text, [offset], [flags])First match's captures as results
rx.match(text, [flags])Whole-string match array, or nil
rx.search(text, [flags])Array of all match arrays, or nil
rx.replace(text, replacement, [flags])Substituted string
rx.split(text, [flags])Array of parts between matches

Method examples

has_num = r'\d+'.test('Order 42')             -- true

text = 'Order 42 ready'
start, stop = r'\d+'.findFirst(text)           -- 6, 8
number = text.sub(start, stop)                 -- '42'

for start, stop in r'\d+'.findAll('x=10, y=20') do
   print(f'[{start}..{stop})')
end

name, id = r'(\w+)-(\d+)'.extract('item-42')   -- 'item', '42'
date = r'(\d{4})-(\d{2})-(\d{2})'.match('2026-09-10')
year = date?[1]                               -- '2026'
all = r'<(\w+)>'.search('<red> <blue>')
first = all?[0][0]                            -- '<red>'

findFirst() and findAll() return zero-based byte positions as half-open spans [start, stop). Capture arrays are also zero-based.

Return conventions

findFirst() / findAll()Capture array excludes the full match; nil when no groups exist
extract()No results when unmatched; optional unmatched captures are empty strings
match() / search()Index 0 is the full match; later indices are captures; unmatched calls return nil

Characters & escaping

PatternMeaning
abcLiteral characters
.Any code point except a line terminator; DOT_ALL includes them
\t \n \v \f \rTab, line feed, vertical tab, form feed, carriage return
\0NULL (U+0000); other octal escapes are unsupported
\cXControl character; X is A–Z or a–z
\xHHTwo-digit hexadecimal character
\uHHHHFour-digit Unicode code point
\u{H...}Unicode code point up to U+10FFFF
\. \* \+Escaped metacharacter, matched literally

Outside a class, escape \ ^ $ . | ? * + ( ) [ ] { } when literal. regex.escape() quotes those characters and - in dynamic text.

Character classes

PatternMeaning
[abc]One of a, b or c
[^abc]Any code point except those listed
[a-z]Inclusive code-point range
[-/] [\-\/]Literal hyphen or slash
[] / [^]Empty set / any code point including line terminators
\d / \DASCII digit / non-digit
\s / \SUnicode whitespace / non-whitespace
\w / \WASCII letter, digit or underscore / complement
\p{...} / \P{...}Unicode property / property complement

A leading ^ negates a class; elsewhere it is literal. Escape ] and ambiguous -. Most other metacharacters lose their special meaning inside a class.

Character-class set operations

[\p{sc=Latin}&&\p{Ll}]Intersection: lowercase Latin
[[A-Za-z]--[AEIOUaeiou]]Subtraction: ASCII consonants
[a-z\q{ch|sh|th}]Characters or listed strings; longest wins
[\p{sc=Latin}--[a-z]]Nested class as an operand

Use one operator type at each nesting level. String properties and \q{...} sequences cannot be complemented. Escape doubled punctuation used as operators or reserved syntax.

Quantifiers

GreedyLazyRepetitions
**?Zero or more
++?One or more
???Zero or one
{n}—Exactly n
{n,}{n,}?At least n
{n,m}{n,m}?n to m, inclusive

Greedy forms consume as much as possible while still succeeding; lazy forms consume as little as possible. <.*> spans to the last >; <.*?> stops at the first.

Pattern Language Tiri Regular Expressions

Alternatives, groups & backreferences

cat|dogFirst successful alternative, left to right
(...)Capturing group; numbered from 1
(?:...)Non-capturing group
(?<name>...)Named capture; also receives a number
\1 \2Text captured by a numbered group
\k<name>Text captured by a named group

Use (?:...) when grouping only controls precedence or repetition. A quantified capture retains its final iteration; a backreference to a non-participating group matches empty text.

Anchors & zero-width assertions

^Start of text; line start with MULTILINE
$End of text; line end with MULTILINE
\b / \BASCII word boundary / non-boundary
(?=...)Positive lookahead
(?!...)Negative lookahead
(?<=...)Positive lookbehind
(?<!...)Negative lookbehind
 
whole_word = r'\bcat\b'              -- not 'concatenate'
bare_amp = r'&(?!amp;|lt;|gt;|#)'
price = r'(?<=£)\d+(?:\.\d{2})?'

Assertions inspect context without consuming text. Inside a class, \b is BEL (U+0008), not a boundary; \B is invalid.

Unicode properties

\p{L}Any letter
\p{Lu} / \p{Ll}Upper-/lowercase letter
\p{N} / \p{Nd}Any number / decimal digit
\p{P} / \p{S}Punctuation / symbol
\p{Z} / \p{C}Separator / other
\p{sc=Greek}Greek script
\p{scx=Latin}Latin script extension
\p{White_Space}Unicode whitespace
\p{Emoji}Emoji property

Identifier: \p{ID_Start}\p{ID_Continue}*. Long names work too: \p{Script=Latin}. \w remains ASCII-oriented; use properties for international text.

Compilation & inline flags

regex.ICASE / (?i:...)Unicode case-insensitive matching
regex.MULTILINE / (?m:...)^ and $ recognise line boundaries
regex.DOT_ALL / (?s:...). includes line terminators
(?ims:...) / (?i-s:...)Enable several / enable i, disable s
 
line = regex.new([[^error:]], regex.ICASE | regex.MULTILINE)
local_case = r'ID-(?i:[a-f0-9]{8})'

Pattern object properties

rx.pattern original pattern · rx.flags compilation mask · rx.error always nil for script-accessible objects.

Match & replacement flags

regex.CONTINUOUSMatch must begin at text position 0
regex.NOT_NULLReject zero-length matches
regex.NOT_BEGIN_OF_LINE / NOT_END_OF_LINESuppress edge line boundaries
regex.NOT_BEGIN_OF_WORD / NOT_END_OF_WORDSuppress edge word boundaries
regex.PREV_AVAILABLEA preceding character is available to assertions
regex.REPLACE_NO_COPYEmit replacements without unmatched text
regex.REPLACE_FIRST_ONLYReplace only the first match

Pass these to an operation, not regex.new(). Do not mix compilation and match flags in one mask.

Replacement placeholders

$0 or $&Full match
$1, $2, …Numbered capture
$<name>Named capture
$` / $'Text before / after the match
$$Literal dollar sign
 
phone = r'(?<area>\d{3})-(?<local>\d{3})-(?<line>\d{4})'
phone.replace('555-123-4567', '($<area>) $<local>-$<line>')
-- '(555) 123-4567'
r'\d+'.replace('1 2 3', 'X', regex.REPLACE_FIRST_ONLY) -- 'X 2 3'
r',\s*'.split('r, g,  b')                             -- {'r','g','b'}

Common recipes

Pattern / operationPurpose
^[+\-]?\d+$Integer shape
^[+\-]?\d+(?:\.\d+)?$Decimal shape
^\d{4}-\d{2}-\d{2}$ISO-style date shape
^\p{ID_Start}\p{ID_Continue}*$Unicode identifier
r'^\s+|\s+$'.replace(text, '')Trim outer whitespace
r'\s+'.replace(text, ' ')Collapse whitespace
\.([A-Za-z0-9]+)$Capture a file extension
<([^>]+)>(.*?)</\1>Text inside simple paired tags

Shape checks do not validate domain semantics; the date pattern accepts impossible dates.

Boundaries & performance

  • Unsupported: \Q...\E, possessive quantifiers, recursion, conditionals, inline comments, POSIX classes, .NET balancing groups and octal escapes other than \0.
  • Compile once and reuse. A deferred expression <{ regex.new(...) }> compiles on first use.
  • Use test() for presence and findFirst() for positions; avoid collecting results unnecessarily.
  • Anchor validation patterns and prefer specific classes over broad .* searches.
  • Avoid ambiguous nested quantifiers such as (a+)+; they can cause catastrophic backtracking.
