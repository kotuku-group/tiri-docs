Tiri Standard Interfaces Cheat Sheet Standard library quick reference

Tiri Standard Interfaces Cheat Sheet

s, a, t, r and rx denote string, array, table, range and compiled regular-expression values. Square brackets mark optional parameters; ... accepts additional values.
