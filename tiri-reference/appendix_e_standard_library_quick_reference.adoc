== Standard Library Quick Reference
indexterm:[library, standard] This appendix provides a compact reference of the built-in Tiri functions organised by library.  For full semantics, see the referenced chapters.

=== Global Functions
indexterm:[global functions] See <<ch-basic-syntax>>, <<ch-types-and-values>>, <<ch-error-handling>>, <<ch-script-management>>.

[cols="4,7",role=compact]
|===
|Signature |Description

|`assert(Condition, [Message])`  |Raises an exception if `Condition` is false.
|`type(Value)`                   |Returns the display name of `Value` for user-facing text.  Honours `pass:[__]name`.
|`rawtype(Value)`                |Returns the runtime type of `Value`, parameterised for containers.  Ignores metamethods.
|`tonumber(Value, [Base])`       |Converts `Value` to a number.  Returns `nil` on failure.
|`tostring(Value)`               |Converts `Value` to a string.  Honours `pass:[__]tostring`, then `pass:[__]name`.  The default representation carries no address.
|`print(pass:[...])`             |Writes arguments to stderr with no separator between them, followed by a newline.
|`msg(pass:[...])`               |Writes arguments to the Kōtuku log at API level.
|`pairs(Table)`                  |Returns an iterator over all key-value pairs.
|`ipairs(Table)`                 |Returns an iterator over sequential integer keys.
|`values(Table)`                 |Returns an iterator over values only.
|`keys(Table)`                   |Returns an iterator over keys only.
|`forEach(Target, Callback)`     |Calls `Callback` for every iterator result of `Target` and returns `Target`.  See <<sec-callback-traversal>>.
|`next(Table, [PrevKey])`        |Returns the next key-value pair after `PrevKey`.
|`rawget(Table, Key)`            |Gets a value bypassing metamethods.
|`rawset(Table, Key, Value)`     |Sets a value bypassing metamethods.  Global environment policy still applies.
|`rawequal(Value1, Value2)`      |Checks equality bypassing metamethods.
|`rawlen(Table)`                 |Returns length bypassing metamethods.
|`setmetatable(Table, Metatable)`|Sets the metatable.  See <<ch-metatables-and-metamethods>>.
|`getmetatable(Value)`           |Returns the metatable.
|`isthunk(Value)`                |Returns `true` if `Value` is an unresolved thunk.  See <<sec-deferred-expressions>>.
|`resolve(Thunk)`                |Evaluates and returns the value of a thunk.  See <<sec-deferred-expressions>>.
|`loadFile(Path)`                |Loads, parses and executes the Tiri source file at `Path`, returning its results.
|`exec(Code)`                    |Parses and executes the Tiri source in `Code`, returning its results.
|`arg(Key, [Default])`           |Returns the named command-line argument, or `Default` if not found.
|===

[cols="4,7",role=compact]

|`arr.clear()`                         |Resets the length to zero.

|===

==== Copying, Slicing, and Conversion

[cols="4,7",role=compact]
|===
|Signature |Description

|`arr.table()`                                   |Converts to a table.

==== Functional Methods

[cols="4,7",role=compact]
|===
|Signature |Description

|`arr.each(Callback)`          |Calls `Callback` for each element.  A callback result of `false` stops the iteration.

|`arr.reduce(Initial, Reducer)`|Folds elements into a single value.
|`arr.any(Predicate)`          |Returns `true` if any element matches.
|`arr.all(Predicate)`          |Returns `true` if all elements match.
|===

Array callbacks receive `(Value, Index)`; `reduce()` receives `(Accumulator, Value, Index)`.

=== Range Library
indexterm:[library, range] See <<ch-ranges>>.

[cols="4,7",role=compact]
|===
|Signature |Description

|`range(Start, Stop, [Inclusive], [Step])`    |Creates a range.
|`range.new(Start, Stop, [Inclusive], [Step])`|Alias for `range()`.
|`range.slice(Object, Range)`|Extracts a slice from an object using a range.
|`r.toArray()`               |Converts the range to an array.
|`r.each(Callback)`          |Calls `Callback` for each value in the range.  A callback result of `false` stops the iteration.
|`r.map(Transform, [ElementType])`|Returns an array of transformed values, typed `ElementType` or `any`.
|`r.filter(Predicate)`       |Returns an array of matching values.
|`r.reduce(Initial, Reducer)`|Folds values into a single result.
|`r.take(Count)`             |Returns an array of the first `Count` values.
|`r.any(Predicate)`          |Returns `true` if any value matches.
|`r.all(Predicate)`          |Returns `true` if all values match.
|`r.find(Predicate)`         |Returns the first value matching `Predicate`.
|`r.findIndex(Predicate)`    |Returns the ordinal of the first value matching `Predicate`.
|`r.indexOf(Value)`          |Returns the ordinal that generates `Value`, or `nil`.
|===

Range callbacks receive `(Value, Ordinal)`; `reduce()` receives `(Accumulator, Value, Ordinal)`.

Range literal syntax: `{0 to 5}` (exclusive), `{0 into 5}` (inclusive).  Membership is tested with the `in` operator: `5 in {0 to 10}`.

Read-only properties: `r.start`, `r.stop`, `r.step`, `r.inclusive`, `r.length`.

==== File Handle Methods

[cols="4,7",role=compact]
|===
|Signature |Description

|`file.read([Format, pass:[...]])`|Reads data.  Formats: `*l` (line), `*a` (all), `*n` (number), or byte count.
|`file.write(Data, pass:[...])`   |Writes data.

`io.stdin`, `io.stdout` and `io.stderr` are numeric stream descriptors, not file handles.  `io.input(io.stdin)` selects standard input.  Open the `std:in`, `std:out` and `std:err` volume paths to obtain a file handle for any of the three streams.
